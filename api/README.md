# SICNU API

Backend du **Système d’information de la Commission nationale UNESCO-RDC**.

Le frontend (racine du dépôt) tourne encore en démonstration. Cette API expose pour l’instant :

- `GET /api/health` — contrôle de vie
- `*` sous `/api` — 501 (à implémenter)

```bash
cd api
npm install
npm run dev
```

Écoute par défaut : `http://localhost:3000`.
